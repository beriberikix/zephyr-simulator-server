# Database Schema — PocketBase Collections

This document describes the data model for the Zephyr Remote Emulator.

## Collections

### `binaries`

Stores metadata about uploaded Zephyr native_sim binaries.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | Text | ✓ | Primary key (UUID generated by PocketBase) |
| `name` | Text | ✓ | Binary filename (e.g., `hello_world.elf`) |
| `bits` | Number | ✓ | Architecture: 32 or 64 |
| `is_static` | Boolean | ✓ | True if statically linked (no `.dynamic` section) |
| `zephyr_version` | Text | ✗ | Extracted Zephyr version (e.g., "4.3.0"); defaults to "4.3.0" |
| `file_path` | Text | ✓ | Absolute path on host (e.g., `/tmp/binaries/hello.elf`) |
| `file_size` | Number | ✓ | Size in bytes |
| `checksum` | Text | ✓ | SHA256 hex digest for integrity verification |
| `created` | DateTime | ✓ | Creation timestamp (auto-managed by PocketBase) |
| `updated` | DateTime | ✓ | Last update timestamp (auto-managed by PocketBase) |

**Indexes:**
- `name` (for searching)
- `checksum` (for deduplication checks)

**Example Record:**
```json
{
  "id": "abc123def456",
  "name": "hello_world.elf",
  "bits": 64,
  "is_static": true,
  "zephyr_version": "4.3.0",
  "file_path": "/tmp/binaries/hello_world.elf",
  "file_size": 2048576,
  "checksum": "a1b2c3d4e5f6...",
  "created": "2026-03-30T10:30:00Z",
  "updated": "2026-03-30T10:30:00Z"
}
```

### `sessions`

Represents active or historical emulator sessions.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | Text | ✓ | Primary key (UUID) |
| `binary_id` | Relation | ✓ | Foreign key → `binaries.id` |
| `state` | Select | ✓ | Enum: `running`, `paused`, `stopped` |
| `seed` | Number | ✗ | RNG seed for deterministic execution (0-2^64-1) |
| `use_real_time` | Boolean | ✗ | Enable `--rt` flag for real-time simulation |
| `container_id` | Text | ✗ | Docker container ID (null if stopped) |
| `timeout_seconds` | Number | ✗ | Session timeout in seconds (default: 300) |
| `uptime` | Number | ✗ | Cumulative runtime in seconds (excluding paused time) |
| `snapshot_data` | JSON | ✗ | Serialized snapshot (see Snapshot schema below) |
| `pcap_file_path` | Text | ✗ | Path to PCAP capture file (Advanced networking) |
| `created` | DateTime | ✓ | Creation timestamp |
| `updated` | DateTime | ✓ | Last update timestamp |

**Indexes:**
- `binary_id` (for querying sessions by binary)
- `state` (for filtering sessions by status)
- `created` (for sorting by creation time)

**Example Record:**
```json
{
  "id": "xyz789abc123",
  "binary_id": "abc123def456",
  "state": "running",
  "seed": 42,
  "use_real_time": false,
  "container_id": "5a1b3c9d7e2f",
  "timeout_seconds": 300,
  "uptime": 127,
  "snapshot_data": {
    "session_id": "xyz789abc123",
    "binary_id": "abc123def456",
    "state": "running",
    "seed": 42,
    "use_real_time": false,
    "created_at": "2026-03-30T10:35:00Z",
    "flags": {
      "seed": 42,
      "use_real_time": false,
      "verbose": true
    },
    "volumes": {
      "flash_path": "/var/lib/zephyr-emu/sessions/xyz789abc123/flash.bin",
      "eeprom_path": "/var/lib/zephyr-emu/sessions/xyz789abc123/eeprom.bin"
    }
  },
  "pcap_file_path": null,
  "created": "2026-03-30T10:35:00Z",
  "updated": "2026-03-30T10:36:30Z"
}
```

**Snapshot Schema** (stored in `snapshot_data` JSON field):
```go
type Snapshot struct {
  SessionID   string                 `json:"session_id"`
  BinaryID    string                 `json:"binary_id"`
  State       string                 `json:"state"` // running|paused|stopped
  Seed        uint64                 `json:"seed"`
  UseRealTime bool                   `json:"use_real_time"`
  CreatedAt   string                 `json:"created_at"` // ISO8601
  Flags       map[string]interface{} `json:"flags"` // all CLI flags
  Volumes     struct {
    FlashPath  string `json:"flash_path"`
    EEPROMPath string `json:"eeprom_path"`
  } `json:"volumes"`
}
```

### `uart_logs`

Optional collection for archiving terminal output history (for long-running sessions).

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | Text | ✓ | Primary key (UUID) |
| `session_id` | Relation | ✓ | Foreign key → `sessions.id` |
| `uart_idx` | Number | ✓ | UART index (0, 1, etc.) |
| `data` | Text | ✓ | Output line (capped at 4KB per record) |
| `created` | DateTime | ✓ | Timestamp when output occurred |

**Indexes:**
- `session_id` (for querying logs by session)
- `uart_idx` (for querying specific UART)
- `created` (for ordering by timestamp)

**Purpose:** Archival only; real-time output uses circular buffer in multiplexer goroutine.

**Example Record:**
```json
{
  "id": "log_abc123",
  "session_id": "xyz789abc123",
  "uart_idx": 0,
  "data": "[00:00:00.001] Booting Zephyr OS...",
  "created": "2026-03-30T10:35:01Z"
}
```

### `configs`

System-wide configuration (singleton pattern).

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | Text | ✓ | Primary key (always "system" for singleton) |
| `default_timeout_sec` | Number | ✓ | Default session timeout (e.g., 300 = 5 min) |
| `default_seed` | Number | ✗ | Default RNG seed (0 = random) |
| `pcap_enabled_default` | Boolean | ✗ | Enable PCAP capture by default (Advanced networking) |
| `max_concurrent_sessions` | Number | ✓ | Max running containers (e.g., 10) |

**Example Record:**
```json
{
  "id": "system",
  "default_timeout_sec": 300,
  "default_seed": 0,
  "pcap_enabled_default": false,
  "max_concurrent_sessions": 10
}
```

## Relationships

### Cascade Behavior

1. **Binary Deletion** — Warn if sessions reference it; mark for cleanup but don't auto-delete
2. **Session Deletion** — Cascade delete related `uart_logs` records
3. **Snapshots** — Stored inline in `sessions.snapshot_data`, no separate table

## Query Examples

### List Active Sessions
```sql
SELECT * FROM sessions WHERE state = 'running';
```

### Get Sessions for a Binary
```sql
SELECT * FROM sessions
WHERE binary_id = 'abc123def456'
ORDER BY created DESC;
```

### Archive UART Logs (optional cleanup)
```sql
DELETE FROM uart_logs
WHERE created < datetime('now', '-7 days')
  AND session_id NOT IN (
    SELECT id FROM sessions WHERE state = 'running'
  );
```

### Find Oldest Active Session (for timeout logic)
```sql
SELECT * FROM sessions
WHERE state = 'running'
ORDER BY updated ASC
LIMIT 1;
```

## Performance Notes

1. **Circular Buffer:** UART multiplexer keeps recent output in RAM (10K lines × 80 char avg ≈ 800KB per session)
2. **Archival:** Optional `uart_logs` archival prevents DB bloat; can be pruned via cron
3. **Session Index:** Fast lookups on `state` and `binary_id` for dashboard queries
4. **Snapshot JSON:** Embedded in `session_data` for atomic persistence; no separate versioning table

## Backup Strategy

1. **Binaries** — Stored on filesystem (`/tmp/binaries/`) with PocketBase metadata
2. **Sessions** — Full state in DB + volume snapshots on host (`/var/lib/zephyr-emu/sessions/`)
3. **Snapshots** — Backed up automatically with DB; restore via Docker volume copy

To backup:
```bash
# Database
sqlite3 /data/pb_data/data.db .dump > backup.sql

# Volumes
tar czf sessions-backup.tar.gz /var/lib/zephyr-emu/sessions/
```
